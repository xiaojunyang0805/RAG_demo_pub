# Pilot proposal for Brightwater Robotics — February 2026

Prepared by Mara Velden for Brightwater Robotics' AGV pilot.

## Drive specification offered

| Item | Value |
|---|---|
| Bus voltage | 48 V |
| Phase current limit | 25 A |
| PWM | 20 kHz |
| CAN | 500 kbit/s |
| Thermal shutdown | 105 °C |
| Controller | Corvid C4-120 |
| Encoder interface | SPI |

## Schedule

Rev A boards in March, pilot drives in May 2026. *(The pilot moved to July 2026 after Rev B.)*
